# راه‌اندازی استودیوی تدوین محلی و اتصال به ChatGPT

این راهنما برای اجرای FilmCraft موجود در همین مخزن است؛ برنامهٔ تدوین جداگانه‌ای از صفر نمی‌سازد و به کلید API هوش مصنوعی نیاز ندارد.

## نکتهٔ حریم خصوصی

مخزن فعلی `alighobadi868/filmcraft` عمومی است. این شاخه هم در همان مخزن عمومی قرار دارد؛ بنابراین هیچ فایل خصوصی، ویدئوی شخصی، رمز یا کلید دسترسی را در آن قرار ندهید. خودِ تدوین را می‌توان محلی انجام داد و فایل‌های رسانه‌ای را در مخزن بارگذاری نکرد.

## اجرای نسخهٔ مرورگری روی رایانه

پیش‌نیازها:
- Rust toolchain نسخهٔ سازگار با `rust-version = "1.95"` در `Cargo.toml`
- هدف WebAssembly: `wasm32-unknown-unknown`
- مرورگر دسکتاپ به‌روز

از ریشهٔ مخزن اجرا کنید:

```bash
rustup target add wasm32-unknown-unknown
cargo xtask web --serve 8080
```

سپس نشانی محلی‌ای را که دستور در خروجی اعلام می‌کند، در مرورگر باز کنید. این دستور از مسیر build وب مستندشده در `apps/filmcraft-web/README.md` استفاده می‌کند. اجرای موفق روی دستگاه واقعی هنوز باید در همان محیط بررسی شود؛ این سند به‌تنهایی نتیجهٔ build را تضمین نمی‌کند.

## ابزارهای رایگان رسانه‌ای

برای تبدیل ویدئو، بررسی فایل‌ها و آماده‌سازی منابع محلی، اسکریپت زیر را اضافه کرده‌ایم:

```bash
./scripts/media-tools.sh check
./scripts/media-tools.sh install
```

این اسکریپت روی Debian/Ubuntu از `apt` و روی macOS از Homebrew برای نصب FFmpeg/ffprobe و yt-dlp استفاده می‌کند. برای نصب روی رایانه، باید خودتان دستور `install` را روی همان رایانه اجرا کنید؛ ثبت اسکریپت در GitHub نرم‌افزار را از راه دور روی دستگاه شما نصب نمی‌کند. در Windows می‌توان FFmpeg و yt-dlp را جداگانه نصب کرد و سپس از نسخهٔ سازگار Bash استفاده کرد.

- **FFmpeg/ffprobe:** تبدیل، برش، بررسی و مونتاژ فایل‌های رسانه‌ای؛
- **yt-dlp:** دریافت منابعی که مجاز به دانلود آن‌ها هستید؛ شرایط و حق نشر سایت مبدأ را رعایت کنید؛
- **FilmCraft:** تدوین در رابط پروژه، مشروط به موفقیت build و آزمون واقعی.

این ابزارها به‌خودی‌خود فیلم‌ساز مولد هوش مصنوعی نیستند. تولید ویدئوی جدید با مدل‌های AI سرویس جداگانه و اعتبار مصرفی می‌خواهد.

## وضعیت ابزارهای تولید ویدئوی هوش مصنوعی

اتصال OpenArt در دسترس است، اما حساب فعلی آن روی طرح Free با 10 اعتبار قرار دارد و فهرست مدل‌های ویدئویی نشان می‌دهد ارزان‌ترین گزینهٔ پیش‌فرض نیز 50 اعتبار می‌خواهد؛ بنابراین در حال حاضر تولید ویدئو از این حساب قابل اجرا نیست. اعتبار یا اشتراک پولی خریداری نشده است. اتصال Magnific نیز در بررسی حساب، 0 اعتبار قابل‌استفاده نشان داده است. برای جلوگیری از هزینهٔ ناخواسته، هیچ خرید یا ارتقای پولی انجام نشده است.

## ساخت و اجرای رابط MCP محلی

در ریشهٔ مخزن:

```bash
cargo build --release -p filmcraft-cli
cargo run --release -p filmcraft-cli -- mcp --bridge 127.0.0.1:9876
```

پیکربندی `.mcp.json` همین مخزن نیز از `filmcraft-cli mcp --bridge 127.0.0.1:9876` استفاده می‌کند. این رابط برای ابزارهای سازگار با MCP روی همان رایانه است؛ به‌تنهایی اتصال مستقیم به حساب ChatGPT را ایجاد نمی‌کند.

## محدودیت اتصال مستقیم ChatGPT

ChatGPT برای اتصال به یک MCP محلی به‌صورت مستقیم طراحی نشده است؛ معمولاً به یک endpoint راه‌دور HTTPS یا Secure MCP Tunnel نیاز دارد. همچنین اتصال MCP سفارشی و مجوزهای نوشتن/تغییر به نوع حساب و تنظیمات دسترسی ChatGPT بستگی دارد. پیش از ساخت تونل یا انتشار endpoint، باید امکان اتصال در حساب کاربر و سطح دسترسی ابزارها تأیید شود.

مستندات رسمی: https://help.openai.com/en/articles/12584461-connecting-custom-mcp-servers-in-chatgpt

## آزمون‌های پیشنهادی پیش از استفاده

1. اجرای `cargo check --workspace` روی رایانهٔ سازگار.
2. اجرای `cargo xtask web --serve 8080` و بازکردن رابط وب.
3. اجرای `./scripts/media-tools.sh check` و نصب ابزارهای محلی در صورت نیاز.
4. واردکردن یک ویدئوی آزمایشی غیرخصوصی، ساخت یک برش کوتاه و بررسی خروجی.
5. اجرای MCP محلی و تأیید اینکه ابزارهای FilmCraft پاسخ می‌دهند.
6. فقط پس از موفقیت این آزمون‌ها، بررسی اتصال امن از راه تونل؛ از بازکردن پورت عمومی بدون احراز هویت خودداری کنید.
